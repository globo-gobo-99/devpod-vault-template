# Agent vault starter

Portable, empty Obsidian starter for notes and small source files. This contains no personal
notes, credentials, account bindings, host paths or copied workspace/plugin state.

- [[Sessions/README|Sessions]] — Daily notes and session receipts.
- [[Wiki/README|Wiki]] — Brief ideas and shared distinctions.
- [[Stacks/README|Stacks]] — Parked topics and return points.
- [[Clippings/README|Clippings]] — Captures awaiting actual human discussion.
- [[Templates/README|Templates]] — Minimal daily and session templates.
- [[Wiki/Setup|Setup]] — One-time config and date choices.

The reviewed `.gobsidian` defaults are opt-in. Open this folder as a new vault, then in
Settings → Files and links → Override config folder, select `.gobsidian` and restart.
Verify the daily-note startup behavior and keyboard shortcuts on your actual device.
