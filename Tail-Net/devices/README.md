The six supported roles for this shared Obsidian vault and Runpod system. Preserve all six notes when copying the template. Fill each note with your own hardware and verified Tailscale identity; a role does not imply tailnet enrollment.

- [dot-box](dot-box.md) — Cloud agent workspace.
- [dev-box](dev-box.md) — Development computer.
- [dev-pod](dev-pod.md) — Hosted development pod.
- [lappy](lappy.md) — Laptop.
- [ipad](ipad.md) — Tablet.
- [mobile](mobile.md) — Phone.

Use these same paths and fields in a private vault. When refreshing this public template, copy structure and explanatory text only; retain placeholders for hardware, addresses, hostnames, account identifiers, and credentials.
