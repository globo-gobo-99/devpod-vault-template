# Starter vault scope

This repository is an empty portable starter. Preserve human prose and capture metadata.
Use created YYYY-MM-DD and modified local-minute ISO timestamps, without guessing old dates.
Do not fetch articles, summarize content, infer reviewed status, or sweep a live personal vault.
Run maintenance only on a named authorized replica and bounded recent-change set with durable
Sync-log coverage checkpoints. Report gaps and ambiguity; skip concurrently changed files.
Never copy live Sync tokens/databases, enable duplicate writers, or invent host-handoff locks.
